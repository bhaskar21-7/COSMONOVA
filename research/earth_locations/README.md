# Earth Location Research

This directory contains per-site research notes for Earth analog candidate locations.

## Expected Contents (to be populated during preparation)

- `atacama.md` — Atacama Desert, Chile
- `devon_island.md` — Devon Island / Haughton Crater, Canada
- `iceland.md` — Icelandic volcanic fields
- `death_valley.md` — Death Valley, USA
- `antarctica.md` — McMurdo Dry Valleys, Antarctica
- `lonar.md` — Lonar Crater, India
- `ladakh.md` — Ladakh cold desert, India
- `rann_of_kutch.md` — Rann of Kutch, India

## Research Template

For each site, document:
1. Geographic coordinates and extent
2. Geological setting
3. Published analog literature (with citations)
4. Available datasets and their coverage
5. Strengths as an analog (for which objective?)
6. Weaknesses and mismatches
7. Data access verification status

> All claims must be sourced. Tag unverified items with [verify].

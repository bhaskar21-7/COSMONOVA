# Contributing to COSMONOVA

Thank you for your interest in contributing to the COSMONOVA project (Planetary Analog Intelligence Platform).

> [!NOTE]
> This project is being prepared for the NASA Space Apps Challenge 2026 (November 14, 2026). Contributions are currently limited to the preparation team.

---

## Current Phase: Pre-Hackathon Preparation

We are in the **preparation phase**. Contributions welcome in:

- 📚 Research and literature review
- 📊 Dataset exploration and verification
- 📝 Documentation improvements
- 🔧 Development environment testing
- 🎨 UI/UX design concepts

Contributions **not appropriate** at this stage:
- ❌ Final application code
- ❌ Similarity engine implementation
- ❌ Competition-ready prototypes
- ❌ Generated scientific results

---

## Guidelines

### Scientific Integrity

1. **Never fabricate data** — all datasets must reference official sources (NASA, ESA, USGS, ISRO)
2. **Never invent API endpoints** — only use documented, publicly accessible data access methods
3. **Distinguish hypotheses from findings** — use qualifying language ("candidate", "screening hypothesis", "proposed")
4. **Include references** — cite sources with author, year, journal/publisher, and URL where applicable
5. **Report limitations** — every claim should note its evidence level and constraints

### Code Standards

- Python 3.11+ compatible
- PEP 8 style (enforced via `flake8`)
- Type hints where practical
- Docstrings for all public functions
- Unit tests for analytical functions

### Git Workflow

1. Create a feature branch from `main`
2. Use descriptive commit messages: `docs: add Lonar crater research notes`
3. Keep commits atomic and focused
4. Submit a pull request with a clear description
5. Request review before merging

### Commit Prefixes

| Prefix | Use |
|--------|-----|
| `docs:` | Documentation changes |
| `research:` | Research notes and literature |
| `env:` | Environment and dependency changes |
| `plan:` | Planning documents |
| `feat:` | New features (hackathon phase only) |
| `fix:` | Bug fixes |
| `test:` | Test additions or modifications |

---

## Team Communication

- All decisions logged in planning documents
- Research findings documented in `/research/` with dates and attribution
- Questions and uncertainties tagged with `[verify]` for team review
